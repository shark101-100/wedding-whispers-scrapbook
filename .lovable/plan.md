## Goal

Перевести палитру сайта с бордово-зелёной на оливковую:
- Акцент (кнопки, выделения, «forest») — оливковый `#6b7340` ≈ `oklch(0.49 0.07 115)`
- Всё остальное (текст, заголовки, «burgundy», ink, бордюры) — тёмно-оливковый `#4a4a2a` ≈ `oklch(0.36 0.05 105)`

## Изменения в `src/styles.css` (`:root`)

Переопределить цветовые токены, не трогая названия классов (Tailwind-классы `text-burgundy`, `text-forest`, `bg-burgundy` и т.д. продолжат работать, просто сменят оттенок):

- `--foreground`, `--ink` → `oklch(0.36 0.05 105)` (тёмная олива)
- `--burgundy` → `oklch(0.36 0.05 105)` (тёмная олива — использовалась для заголовков/основного)
- `--burgundy-soft` → `oklch(0.46 0.06 105)`
- `--forest` → `oklch(0.49 0.07 115)` (акцентная олива)
- `--forest-soft` → `oklch(0.58 0.07 115)`
- `--accent` остаётся `var(--forest)` — автоматически станет акцентной оливой
- `--primary` остаётся `var(--burgundy)` — станет тёмной оливой
- `--ring` → акцентная олива
- `--border`, `--input` → приглушённый оливковый бежево-серый `oklch(0.78 0.02 100)`
- `--muted-foreground` → `oklch(0.5 0.03 100)`

Фон (ivory) и бежевые тона (`--beige`, `--paper`) оставляем как есть — это «бумага».
