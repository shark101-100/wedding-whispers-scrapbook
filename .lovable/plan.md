## Блок «Организационные моменты»

Добавлю новую секцию в `src/routes/index.tsx` между блоком «место встречи» (строка 268) и существующим блоком «дресс-код» (строка 271). Существующий блок дресс-кода будет интегрирован в новый раздел как подпункт, чтобы избежать дублирования.

### Структура

Заголовок-чаптер `Организационные моменты` (font-script, бордо) + вступительный текст, затем три карточки-полароида с лентой (`PolaroidNote`), каждая с разным наклоном для скрапбук-эффекта, и анимацией `Reveal` со стэггером.

```text
┌─────────────────────────────────┐
│   Организационные моменты       │
│   (вводный текст про 18+)       │
│                                 │
│   ┌──── Полароид ────┐          │
│   │  ✦ трансфер       │          │
│   │  текст…            │          │
│   └───────────────────┘          │
│                                 │
│      ┌──── Полароид ────┐        │
│      │  ✦ дресс-код      │        │
│      │  текст + цвета   │        │
│      └──────────────────┘        │
└─────────────────────────────────┘
```

### Содержание карточек

1. **Вступление** (без карточки, как «наша история»): «Чтобы создать по-настоящему расслабленную и праздничную атмосферу для всех гостей, мы решили провести наш вечер в формате только для взрослых».
2. **Трансфер** (`PolaroidNote`, rotate -1.5deg): подзаголовок `font-hand` «трансфер», основной текст про близость к городу и свободное расписание.
3. **Дресс-код** (`PolaroidNote`, rotate 1.8deg): подзаголовок «дресс-код», текст про комфорт и эстетику, строка `бордо · олива · бежевый`, три цветных кружка (переиспользую существующую палитру `#6b2535`, `#4a5d3a`, `#c9b48a` с `animate-pop`).

### Технические детали

- Использую существующие компоненты `Reveal` (variant="paper", `delay` для стэггера) и `PolaroidNote`.
- Семантические токены: `text-burgundy`, `text-forest`, `text-ink/80`, `font-script`, `font-hand`, `font-serif-display` — без хардкода цветов, кроме swatches цветовой палитры дресс-кода (как сейчас).
- Удалю старый отдельный блок `{/* Dress code */}` (строки 270–288) — его содержимое переезжает внутрь новой секции.
- Вставка между `{/* Place */}` и `{/* RSVP */}`. Отступ `mt-20`, как у соседних секций.
- Между карточками — `space-y-12`, чередующиеся наклоны для живости.
