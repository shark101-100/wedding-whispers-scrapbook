## План: добавить мягкие анимации в стиле scrapbook

Добавим деликатные, не отвлекающие анимации, которые поддерживают рукотворную «бумажную» эстетику — без резких эффектов и неона.

### 1. Появление секций при скролле (reveal-on-scroll)

- Создать небольшой хук `src/hooks/use-in-view.ts` поверх `IntersectionObserver` (без новых зависимостей).
- Создать обёртку `src/components/Reveal.tsx`: при попадании в вьюпорт добавляет класс `is-visible`. Принимает проп `delay` для каскадного появления.
- Обернуть в `src/routes/index.tsx` ключевые блоки: header, date card, story, schedule (каждый пункт списка с нарастающей задержкой), place, dress code, RSVP, footer.

Эффект: лёгкий fade + подъём на ~12px + микро-поворот (имитация «прикладываемой» бумажки), длительность 600–800 мс, easing `cubic-bezier(.2,.7,.2,1)`.

### 2. CSS-анимации в `src/styles.css`

Добавить keyframes и утилиты:

- `paper-in` — fade + translateY(12px) + лёгкий rotate, для блоков-«карточек» (PolaroidNote сохраняет свой исходный rotate через CSS-переменную).
- `sketch-in` — для иллюстраций: fade + scale(0.92) → 1 + лёгкое покачивание.
- `ink-draw` — для декоративной линии `.ink-line`: маска с анимацией `clip-path: inset(0 100% 0 0)` → `inset(0 0 0 0)` (имитация «дорисовки» чернилами).
- `float-soft` — бесконечное мягкое покачивание ±3° для мелких иллюстраций (heart, rose) — очень медленное (6–8s), `prefers-reduced-motion: reduce` отключает.
- `tape-press` — для скотча: scaleX от 0 до 1 при появлении карточки.
- Утилиты: `.reveal`, `.reveal.is-visible`, `.animate-float`, `.animate-sketch-in`, `.animate-ink-draw`.
- Глобально уважать `@media (prefers-reduced-motion: reduce)` — отключать transform/opacity-анимации.

### 3. Hover/tap-микроанимации

- Кнопки RSVP («буду» / «не смогу»): при hover — лёгкий tilt (±1.5°) и сдвиг на 1px вверх; при активном выборе — мягкий «штамп» (scale 0.96 → 1.02 → 1) через keyframe `stamp`.
- Кнопка отправки: при hover — едва заметное покачивание (±0.5°).
- Счётчик гостей: при изменении числа — `scale-in` на цифре (key-based remount по значению, либо CSS-анимация на `key={count}`).
- Ссылка «открыть на карте»: подчёркивание-«рисунок» от 0 до 100% слева направо при hover.

### 4. Финальный экран RSVP

После успешной отправки в `RsvpForm`:

- Картинка колец — `sketch-in` + бесконечное `float-soft`.
- Текст «спасибо!» — `paper-in` с задержкой 150 мс.
- Подзаголовок — `paper-in` с задержкой 300 мс.

### 5. Загрузка страницы

При первом рендере хедер (имя «Анна & Михаил» и florals) появляется через `paper-in` сразу, без ожидания скролла — задержки 0/150/300/450 мс для последовательного выхода: «приглашаем» → florals → имена → подпись.

### Технические детали

- `Reveal` использует `useRef`, `unobserve` после первого срабатывания, `rootMargin: "0px 0px -10% 0px"`.
- Сохранить существующие `transform: rotate(...)` у `PolaroidNote` и `.deco-rotate-*`: анимации применяем через отдельные CSS-переменные (`--reveal-y`, `--reveal-rot`) и комбинируем в `transform` так, чтобы базовый поворот элемента не терялся. Где это сложно (PolaroidNote с inline-стилем), завернём содержимое в дополнительный wrapper, который и анимируется.
