## Новое сердце вокруг даты

Сейчас path обведения непропорционален: верхние «горбы» сжаты, нижний кончик уходит за рамки колонки, и форма растягивается из-за `preserveAspectRatio="none"`. Переделаю SVG и добавлю анимацию рисования «от руки».

### Что меняется в `src/routes/index.tsx` (блок с цифрой 5, ~строки 109–125)

1. **SVG-контейнер**
   - Убрать `preserveAspectRatio="none"` — пусть сердце сохраняет пропорции.
   - Поменять `viewBox` на квадратный `0 0 100 90` и центрировать через `flex` обёртку.
   - Размер: задать сердцу фиксированный размер (`h-24 w-24 sm:h-20 sm:w-20`) и поставить цифру `5` поверх через `absolute`.

2. **Path сердца — нарисованный от руки, симметричный**
   - Один непрерывный путь, начинающийся и заканчивающийся в одной точке (нижний кончик), с лёгкой «дрожью» линии для рукописного эффекта.
   - Примерная форма (две дуги сверху, плавный V-образный низ):
     ```
     M50 82
     C 30 70, 8 56, 12 34
     C 14 18, 32 10, 44 22
     C 47 26, 49 30, 50 34
     C 51 30, 53 26, 56 22
     C 68 10, 86 18, 88 34
     C 92 56, 70 70, 50 82 Z
     ```
   - `stroke-width="2.5"`, `stroke-linecap="round"`, `stroke-linejoin="round"`, лёгкий наклон `rotate(-4deg)` для «живого» вида.

3. **Анимация рисования** (через CSS в `src/styles.css`)
   - Добавить keyframes `draw-heart`:
     ```css
     @keyframes draw-heart {
       from { stroke-dashoffset: 320; }
       to   { stroke-dashoffset: 0; }
     }
     .animate-draw-heart {
       stroke-dasharray: 320;
       stroke-dashoffset: 320;
       animation: draw-heart 1.6s ease-out forwards;
       animation-delay: 600ms;
     }
     ```
   - Применить класс `animate-draw-heart` к `<path>`.
   - После отрисовки добавить лёгкое «дыхание» цифры `5` — переиспользовать существующий `animate-float` или ничего не добавлять (на выбор пользователя).

### Технические детали

- Сердце рисуется один раз при загрузке секции (Reveal уже даёт fade-in контейнера, анимация stroke стартует поверх).
- Длина пути ~320 единиц подобрана под `viewBox` 100×90; при изменении path обновить `stroke-dasharray`.
- Цифра `5` остаётся в `font-script text-burgundy`, размер не меняется.
